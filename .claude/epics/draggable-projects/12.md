# Task: 实现项目拖拽排序与顺序持久化

## 描述
为 PIQ menubar 的项目列表添加拖拽排序功能。在 ProjectConfig 中新增 `projectOrder: [String]` 字段存储用户自定义的项目顺序，在 MenuBarView 中为 ForEach 添加拖拽支持，在 AppState 中添加排序逻辑使 rescanAll() 后保持用户指定的顺序。

## 验收标准
- [ ] ProjectConfig 新增 `projectOrder` 字段，自定义 Codable 正确编解码
- [ ] 项目卡片可通过拖拽重新排序
- [ ] 拖拽完成后顺序立即持久化到 `~/.piq/projects.json`
- [ ] rescanAll() 后项目顺序保持不变
- [ ] 关闭/重新打开 popover 后顺序保持不变
- [ ] 退出/重启应用后顺序保持不变
- [ ] 新发现的项目自动追加到列表末尾
- [ ] 已删除项目从 projectOrder 中自动清除
- [ ] 不影响现有功能（展开状态、快捷操作、上下文菜单）

## 技术细节

### 1. ProjectConfig.swift
- 添加 `var projectOrder: [String] = []` 属性
- `CodingKeys` 添加 `projectOrder` case
- `init(from:)` 添加 `projectOrder` 解码（`decodeIfPresent`，默认空数组）
- `encode(to:)` 添加 `projectOrder` 编码

### 2. AppState.swift
- 添加 `moveProjects(from: IndexSet, to: Int)` 方法：
  - 调用 `projects.move(fromOffsets:toOffset:)`
  - 更新 `projectConfig.projectOrder`
  - 调用 `saveProjectConfig()`
- 添加 `reorderProjects()` 方法：
  - 根据 `projectConfig.projectOrder` 排序 `projects`
  - 不在 order 中的项目追加末尾
  - 清除 order 中已不存在的路径
- `rescanAll()` 末尾调用 `reorderProjects()`

### 3. MenuBarView.swift
- 方案 A（优先尝试）：将 `ScrollView` + `LazyVStack` + `ForEach` 替换为 `List` + `ForEach` + `.onMove`
  - 使用 `.listStyle(.plain)` 匹配当前无边框外观
  - 需测试在 MenuBarExtra window 中是否正常工作
- 方案 B（备选）：保持 `ScrollView` + `LazyVStack`，使用 `.draggable(project.id)` + `.dropDestination` 手动实现拖拽

### 涉及文件
- `PIQ/Models/ProjectConfig.swift`
- `PIQ/App/AppState.swift`
- `PIQ/Views/MenuBarView.swift`
