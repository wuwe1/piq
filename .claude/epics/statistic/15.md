# Task: MenuBarView 统计入口集成

## 描述
在 MenuBarView 的 header 区域添加统计按钮，点击后将 content 区域从项目列表切换为 StatsView。统计视图有返回按钮切回项目列表。确保 AppState.setupActivityStore() 在应用启动时被调用。

## 验收标准
- [ ] header 右侧有统计图标按钮（chart.bar）
- [ ] 点击统计按钮，content 区域切换为 StatsView
- [ ] StatsView 有返回按钮回到项目列表
- [ ] 切换流畅，无闪烁
- [ ] AppState.setupActivityStore() 在 .task 中被调用
- [ ] 构建零错误零警告

## 技术细节

### MenuBarView.swift 修改
- 添加 `@State private var showStats = false`
- header 中添加统计按钮：
  ```swift
  Button { showStats.toggle() } label: {
      Image(systemName: showStats ? "list.bullet" : "chart.bar")
  }
  ```
- content 区域：
  ```swift
  if showStats {
      StatsView()
  } else if appState.projects.isEmpty {
      emptyState
  } else {
      projectList
  }
  ```

### PIQApp.swift 修改（如需要）
- 确认 `.task` 中调用 `appState.setupActivityStore()`
