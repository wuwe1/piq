### StatsView.swift
- 接收 `@Environment(AppState.self)` 访问 projects 和 activityStore
- Summary Section：遍历 `appState.projects` 计算统计
- Trend Section：`import Charts`，使用 `Chart { ForEach { BarMark } }`
- Activity Section：`ForEach(events.reversed())` + `ActivityRowView`
- 整体包裹在 ScrollView 中

### ActivityRowView.swift
- 接收 `let event: ActivityEvent`
- 使用 `RelativeDateTimeFormatter` 显示相对时间
- 类型图标：prd → "doc.text"，epic → "list.bullet.rectangle"，task → "checklist"
- 状态变更：旧状态 → 新状态，使用 StatusBadge
