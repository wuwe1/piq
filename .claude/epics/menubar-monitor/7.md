# Task: 状态面板 UI

## 描述
实现 MenuBarExtra 的完整 UI 层，包括：MenuBarView 主面板、ProjectCardView 项目摘要卡片（含 worktree 子节点）、ProjectDetailView 展开详情（PRD/Epic/Task 列表 + 一致性警告 + GitHub 链接）。数据由 AppState 驱动，AppState 调用 ProjectScanner 获取数据。

## 验收标准
- [ ] MenuBarView 显示项目列表，每个项目一个 ProjectCardView
- [ ] ProjectCardView 显示：项目名称、PRD 统计、Epic 统计、Task 统计、进度条（tasks_done/task_count）
- [ ] ProjectCardView 下方显示关联的 worktree 子节点
- [ ] 点击项目名称展开 ProjectDetailView
- [ ] ProjectDetailView 显示 PRD 列表（名称 + 状态标签）
- [ ] ProjectDetailView 显示 Epic 列表（名称 + 进度条 + tasks_done/task_count + 状态）
- [ ] ProjectDetailView 显示 Task 列表（编号 + 名称 + 状态）
- [ ] 一致性不一致时显示 ⚠️ 标记
- [ ] github 字段非空的项显示链接图标
- [ ] 面板底部显示 Settings 和 Copy Status 按钮
- [ ] AppState 启动时调用 ProjectScanner 加载数据

## 技术细节
- AppState (@Observable)：持有 [Project] 数组，启动时从 ProjectScanner 加载
- MenuBarView：ScrollView 包裹项目列表 + 底部工具栏
- ProjectCardView：VStack，DisclosureGroup 用于展开/折叠
- ProjectDetailView：List 或 LazyVStack 展示 PRD/Epic/Task
- 进度条：自定义 ProgressView 或 GeometryReader 实现像素风格进度条
- 状态标签：用不同颜色区分 backlog(灰)/in-progress(蓝)/done(绿)/open(橙)
- Popover 固定宽度 360，高度自适应（最大 600）
