# Task: ProjectScanner、项目发现与一致性校验

## 描述
实现 ProjectScanner 服务，负责：1) 扫描根目录自动发现含 .claude/ 的项目；2) 解析项目内所有 PRD/Epic/Task 文件并聚合为 Project 模型；3) 通过 git worktree list 发现关联 worktree；4) 对每个 Epic 进行一致性校验（tasks_done vs 实际 task 文件统计）。同时实现项目配置的 JSON 持久化。

## 验收标准
- [ ] 给定根目录路径，能递归发现所有含 .claude/prds/ 或 .claude/epics/ 的子目录
- [ ] 扫描 .claude/prds/*.md 解析为 PRDItem 列表
- [ ] 扫描 .claude/epics/*/epic.md 解析为 EpicItem，扫描同目录下 *.md（type: task）解析为 TaskItem
- [ ] 调用 git worktree list 解析输出，识别关联 worktree
- [ ] EpicItem.actualTasksDone 通过扫描 task 文件中 status == done 的数量得出
- [ ] 项目配置（扫描根目录列表 + 手动添加项目列表）持久化到 ~/.piq/projects.json
- [ ] 支持手动添加项目路径，与自动发现结果合并
- [ ] 目录不存在或权限不足时优雅降级（跳过，不崩溃）
- [ ] 单元测试覆盖扫描逻辑和一致性校验

## 技术细节
- ProjectScanner.swift：
  - scanRootDirectory(url: URL) -> [Project]：递归扫描
  - scanProject(url: URL) -> Project：单个项目解析
  - discoverWorktrees(projectURL: URL) -> [Worktree]：执行 Process("git", "worktree", "list", "--porcelain") 解析输出
  - verifyConsistency(epic: EpicItem, tasks: [TaskItem]) -> Bool
- ProjectStore（或在 AppState 中）：
  - load/save projects.json
  - 合并自动发现 + 手动添加（手动添加的 isManual 标记，不被自动扫描覆盖）
