# Task: FSEvents 实时文件监控

## 描述
实现 FileWatcher 服务，使用 macOS FSEvents API 监控所有被监控项目的 .claude/prds/ 和 .claude/epics/ 目录。文件变更时触发增量解析，通过 AppState 驱动 UI 自动更新。包含 500ms debounce 和定时全量重扫（每 5 分钟）作为兜底。

## 验收标准
- [ ] FileWatcher 能同时监控多个目录路径
- [ ] 文件创建、修改、删除事件都能检测到
- [ ] 500ms debounce：短时间内多次变更只触发一次解析
- [ ] 变更后仅增量解析受影响的文件（非全量重扫）
- [ ] 每 5 分钟自动全量重扫作为兜底（防止 FSEvents 丢事件）
- [ ] 项目被添加时自动注册新的监控路径
- [ ] 项目被移除时自动注销监控
- [ ] AppState 收到更新后 UI 自动刷新
- [ ] CPU 空闲时监控开销 < 1%

## 技术细节
- FileWatcher.swift：
  - 使用 FSEvents C API（FSEventStreamCreate）监控目录树
  - 或使用 DispatchSource.makeFileSystemObjectSource（per-file，适合少量文件）
  - 推荐 FSEvents C API：可递归监控整个目录树，更适合我们的场景
  - kFSEventStreamCreateFlagFileEvents 标志获取文件级事件
  - debounce：收到事件后启动 500ms DispatchWorkItem，重复事件取消前一个
  - 增量解析：事件携带文件路径，仅对该路径调用 FrontmatterParser
  - 全量重扫：Timer.scheduledTimer 每 300 秒触发 ProjectScanner.rescan()
- 集成到 AppState：FileWatcher 持有 AppState 弱引用，更新数据
