# Task: 通知系统、设置界面与最终打磨

## 描述
实现完整的设置界面（SettingsView）、macOS 通知系统（NotificationService）和最终的 UI 打磨。设置界面包括：通用设置（开机自启、图标样式）、项目设置（扫描根目录管理、手动项目管理）、通知设置（全局开关、按项目/事件类型配置）、数据管理（历史保留、导出）。通知系统在状态变更时推送 macOS 系统通知。最终打磨包括像素风图标设计和性能优化。

## 验收标准
- [ ] SettingsView 包含 4 个 Tab：通用、项目、通知、数据
- [ ] 通用设置：开机自启动（ServiceManagement LoginItem）、menubar 图标样式选择
- [ ] 项目设置：扫描根目录列表管理（添加/移除）、手动项目管理、项目隐藏/显示
- [ ] 通知设置：全局开关、按项目配置、按事件类型配置（里程碑/完成/异常）、免打扰时间段
- [ ] 数据管理：活动历史保留天数配置、导出 JSON/CSV 按钮
- [ ] NotificationService：Epic 进度到达 25%/50%/75%/100% 时通知
- [ ] NotificationService：Task 状态变更通知
- [ ] NotificationService：新 PRD 创建通知
- [ ] NotificationService：一致性异常通知
- [ ] 首次请求通知权限（UNUserNotificationCenter.requestAuthorization）
- [ ] 像素风 menubar 图标设计完成（静态 + in-progress 动画状态）
- [ ] 性能测试：10 个项目同时监控，内存 < 50MB
- [ ] 所有设置持久化到 ~/.piq/settings.json

## 技术细节
- SettingsView.swift：TabView 包裹 4 个 Tab
  - GeneralSettingsTab：SMAppService.mainApp.register() 开机自启
  - ProjectSettingsTab：扫描根目录 List + 添加/移除、手动项目 List
  - NotificationSettingsTab：Toggle 控件群组
  - DataSettingsTab：Stepper 保留天数 + 导出按钮
- NotificationService.swift：
  - 使用 UNUserNotificationCenter
  - requestPermission()：首次启动请求权限
  - sendNotification(title, body, category)
  - 检查通知配置，决定是否发送
  - 免打扰模式：检查当前时间是否在静默时段
- 设置持久化：Settings struct + Codable + JSON 文件
- 图标：Assets.xcassets 中准备 16x16 像素图标（1x/2x），使用 SF Symbols 或自定义 pixel art
- 性能：Instruments 检查内存和 CPU
