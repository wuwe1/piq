# Task: 数据模型与自定义 Frontmatter 解析器

## 描述
实现所有数据模型（ItemStatus、ItemType、Project、Worktree、PRDItem、EpicItem、TaskItem、ActivityEvent）和自定义 frontmatter 解析器。解析器读取 markdown 文件的 `---` 之间内容，通过 `type` 字段分发到对应的数据模型。不引入任何第三方 YAML 库。

## 验收标准
- [ ] ItemStatus 枚举实现（backlog, open, in-progress, done）
- [ ] ItemType 枚举实现（prd, epic, task）
- [ ] Project、Worktree、PRDItem、EpicItem、TaskItem、ActivityEvent 模型全部实现
- [ ] EpicItem 包含 progressPercent 计算属性和 isConsistent 校验属性
- [ ] FrontmatterParser 能解析 string、int、bool 值类型
- [ ] FrontmatterParser 通过 type 字段正确分发到 PRDItem / EpicItem / TaskItem
- [ ] 解析器容错：缺少 type 字段、格式异常时返回 nil 而非崩溃
- [ ] 单元测试覆盖：正常解析、缺失字段、空文件、格式错误

## 技术细节
- FrontmatterParser.swift：读取文件内容，定位第一对 `---` 之间的行，逐行用 `:` 分割为 key-value
- 值类型推断：纯数字 → Int，true/false → Bool，"" 或 '' 包裹 → String（去引号），[] → 空数组
- 解析结果为 [String: Any] 字典，再根据 type 字段 mapping 到具体 struct
- 所有模型遵循 Identifiable, Codable 协议
- ISO 8601 日期解析使用 ISO8601DateFormatter
