# Task: 快捷操作与终端集成

## 描述
在 UI 层添加交互功能：点击 PRD/Epic/Task 名称打开文件、右键菜单（Finder 中显示、复制路径）、命令复制（/pm:epic-show、/pm:issue-start、cd 路径）、GitHub 链接跳转、终端打开项目目录、打开 Claude Code。

## 验收标准
- [ ] 点击 PRD/Epic/Task 名称 → NSWorkspace.open 在默认编辑器中打开 .md 文件
- [ ] 右键菜单"在 Finder 中显示" → NSWorkspace.activateFileViewerSelecting
- [ ] 右键菜单"复制文件路径" → NSPasteboard 写入相对路径
- [ ] 点击 Epic → 复制 `/pm:epic-show {name}` 到剪贴板，显示 toast 提示
- [ ] 点击 Task → 复制 `/pm:issue-start {number}` 到剪贴板
- [ ] 点击项目名 → 复制 `cd {path}` 到剪贴板
- [ ] github 字段非空时点击链接图标 → NSWorkspace.open(URL) 在浏览器中打开
- [ ] 项目卡片上"终端"按钮 → 在默认终端中打开项目目录
- [ ] 项目卡片上"Claude Code"按钮 → 执行 `claude` 命令打开到该项目
- [ ] Copy Status 按钮 → 将项目状态摘要（纯文本）复制到剪贴板

## 技术细节
- 文件打开：NSWorkspace.shared.open(fileURL)
- Finder 显示：NSWorkspace.shared.activateFileViewerSelecting([fileURL])
- 剪贴板：NSPasteboard.general.setString(text, forType: .string)
- 终端打开：
  - 检测默认终端（Terminal.app / iTerm2）
  - 使用 AppleScript 或 `open -a Terminal {path}`
- Claude Code：Process("/usr/bin/env", arguments: ["claude", "--project", path])
- 右键菜单：SwiftUI .contextMenu { } modifier
- Toast 提示：自定义 overlay view，2 秒后消失
