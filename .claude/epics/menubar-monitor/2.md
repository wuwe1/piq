# Task: Xcode 项目初始化与 MenuBarExtra 骨架

## 描述
创建 PIQ 的 Xcode 项目结构，配置 Swift 6 + SwiftUI，实现 MenuBarExtra(.window) 骨架应用。App 启动后在 menubar 显示一个像素风图标，点击弹出空的 popover 窗口。这是所有后续任务的基础。

## 验收标准
- [ ] Xcode 项目创建完成，目标 macOS 14+，Swift 6
- [ ] App 使用 MenuBarExtra(.window) 模式，无 Dock 图标（LSUIElement = true）
- [ ] Menubar 显示一个占位像素风图标
- [ ] 点击图标弹出空的 popover 窗口（固定大小，约 360x500）
- [ ] AppState 类使用 @Observable macro，作为全局状态容器
- [ ] 项目目录结构符合 PRD 定义（App/Models/Services/Views/Utilities/Resources）
- [ ] ~/.piq/ 目录在首次启动时自动创建
- [ ] 编译无警告，可运行

## 技术细节
- 使用 SwiftUI App protocol，@main 入口
- MenuBarExtra("PIQ", image: "menubar-icon") { ... } .menuBarExtraStyle(.window)
- Info.plist 设置 LSUIElement = true 隐藏 Dock 图标
- AppState 作为 @Observable class，注入到环境中
- 创建 ~/.piq/ 目录用于后续数据存储
- Resources/Assets.xcassets 中放置占位 menubar 图标（16x16 像素）
